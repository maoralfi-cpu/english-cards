# כרטיסיות אנגלית לילדים (english-cards)

אפליקציית HTML אחת (`index.html`) לתרגול מילים באנגלית: כרטיסייה הפוכה, הקראה, ערבוב, כוכבים וקונפטי.

- **כתובת:** https://maoralfi-cpu.github.io/english-cards/
- **מאגר:** maoralfi-cpu/english-cards, ענף main, GitHub Pages מהשורש.
- **עדכון מילים:** מערך `allWords` בסקריפט: `{e:"word", h:"תרגום", icon:"😀", isNew:true}`. אחרי שינוי מעדכנים גם את המספרים בכפתורים `הכל (N)` / `חדשות (M)` ואת `1 / N`.
- **פריסה:** `git commit` + `git push origin main` (gh מחובר בקופסה), ואז מחכים לבנייה של Pages (`gh api repos/maoralfi-cpu/english-cards/pages/builds/latest`).
